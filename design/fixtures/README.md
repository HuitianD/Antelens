# UI screenshot fixture

`rental-checkout.html` is a static illustrative page matching the synthetic rental scenario's $40 fee and required $29 monthly membership. Playwright renders it at a 1000×760 viewport and device scale 2 to `apps/web/public/demo/rental-checkout.png`.

The frontend displays this image only in explicit demo mode for synthetic/simulated Maple evidence with no captured artifact. It is labeled **Demo screenshot** and **Not a live browser capture**. Live evidence uses the existing authenticated evidence API and never falls back to this image.

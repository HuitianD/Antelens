3. **Previously completed fallback:** another tab with the same case URL. Its existing version 7 was reviewed before release preparation; version 6 is the saved owner-Chrome capture. Under **Assessment history**, expand **Version 6**, then **Evidence cited in this version**. Announce it as **“Previously completed run — not this capture.”** Do not refresh/reset/rewrite it to make it appear new. If the current pointer has advanced, use the history version and its displayed timestamp, not a presumed latest version number.

Record the current version before the fresh capture. Existing real standalone captures took **64.2 and 97.5 seconds** from capture to persisted assessment; the saved linked owner-Chrome capture took **64.1 seconds**. These are measured examples, not guarantees. A second check can queue behind the first. Do not promise instant completion, invent progress, or increase a timeout for the presentation.
